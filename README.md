## 简介

「Awa自动翻译中文」是一个 Chrome 扩展（Manifest V3）。安装后访问任何外语网页，都会**自动检测并整页翻译成中文（简体）**，无需任何点击。翻译后的页面右下角会出现一个小控制条，可随时在「中文 / 原文」之间一键切换。

> 灵感来自 Google 官方翻译扩展（2.0.17），本项目为独立实现，未使用其任何代码。

📖 **新手请看图文详细教程：[docs/使用教程.md](docs/使用教程.md)**

## 功能特性

- **全自动翻译**：页面加载后自动检测语言，非中文内容自动译为中文
- **智能跳过**：本身已是中文的页面/段落、纯数字符号、代码块、隐藏元素自动跳过，不浪费请求
- **动态补翻**：监听页面 DOM 变化，懒加载、无限滚动、SPA 路由切换后出现的新内容自动翻译
- **属性也能翻**：除正文外，链接文字、`title` 提示、`placeholder` 占位符、`alt` 图片描述、`aria-label` 一并不放过
- **一键还原**：所有修改基于原文即时替换，随时可完整恢复，刷新页面同样还原
- **悬浮控制条**：右下角常驻，实时显示翻译状态与已翻译处数
- **弹窗面板**：查看当前站点状态，支持立即翻译 / 恢复原文 / 全局开关 / 单站点开关
- **缓存与限流控制**：翻译结果本地缓存（相同内容不重复请求），并发请求池控制，失败自动切换备用接口
- **隐私友好**：仅向翻译接口发送待翻译文本，不收集任何个人信息

## 安装教程

### 方法一：加载已解压的扩展（推荐）

1. 下载本项目代码（点仓库页面右上角绿色 `Code` → `Download ZIP`，下载后解压）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 打开页面右上角的 **「开发者模式」** 开关
4. 点击左上角 **「加载已解压的扩展程序」**
5. 选择解压出来的 `Awa自动翻译中文` 文件夹（即有 `manifest.json` 的那一层）
6. 完成！浏览器工具栏会出现蓝色「文」字图标

![安装步骤](docs/install-steps.png)

> **注意**：安装之前已经打开的页面不会自动注入，**刷新一下页面**即可生效。

### 方法二：已有 zip 包

如果你拿到的就是 `Awa自动翻译中文_v1.0.0.zip`：先解压，再按方法一的第 2～5 步操作（加载的是**解压后的文件夹**，不要直接拖 zip）。

## 使用教程

### 1. 自动翻译（默认状态）

安装后无需任何设置——

- 打开英文等外语网页 → 自动整页翻译成中文
- 打开中文网页 → 自动跳过，不翻译
- 页面右下角出现控制条：`● Awa 已翻译为中文（已译 N 处）`

### 2. 悬浮控制条

| 元素      | 作用                  |
| ------- | ------------------- |
| 左侧状态点   | 橙色 = 正在翻译，绿色 = 翻译完成 |
| `中文` 按钮 | 重新翻译本页              |
| `原文` 按钮 | 一键恢复整页原文            |
| `×`     | 收起控制条（刷新页面后恢复）      |

### 3. 工具栏弹窗

点击浏览器工具栏的扩展图标，可以看到：

- **当前站点 / 翻译状态 / 已翻译处数**
- **立即翻译此页**：手动触发一次整页翻译
- **恢复原文**：把本页恢复成原始语言
- **全局自动翻译**：总开关。关掉后任何网页都不再自动翻译
- **翻译当前网站**：站点级开关。取消勾选后，只有这个网站不再自动翻译（已打开的页面需刷新生效）

## 常见问题（FAQ）

**Q：安装后网页没有反应？**  
A：安装前就已打开的页面需要刷新；`chrome://` 页面、Chrome 应用商店页面因浏览器限制无法注入。

**Q：为什么有的内容没被翻译？**  
A：以下内容会被有意跳过：中文内容、纯数字/符号、代码块（`code`/`pre`）、隐藏元素、输入框正在编辑的内容。

**Q：翻译失败/显示“翻译失败”？**  
A：点击控制条上的「中文」按钮重试即可。扩展内置了三级接口自动降级，一般无需干预。

**Q：支持翻译成繁体中文或其他语言吗？**  
A：当前版本固定翻译为简体中文（`zh-CN`），与扩展名称对应。

**Q：会不会很慢？**  
A：首次翻译取决于网络；相同内容有本地缓存，重复访问同一站点几乎瞬间完成。
